# QuickSnap releases

Installers for **QuickSnap**, a screen capture and screenshot annotation tool.
Website: https://quicksnaptool.com

> **Preview builds.** These installers are early, **unsigned** and only lightly tested.
> Windows SmartScreen and macOS Gatekeeper will warn you. Verify each download against `SHA256SUMS.txt`.

| Platform | File type | Status |
|---|---|---|
| Windows 10/11 (x64) | `.exe` setup installer | Preview, tested on Windows 10 only |
| macOS (Apple Silicon) | `.dmg` | Built by CI, **not tested** |
| Linux (x64) | `.deb` | Built by CI, **not tested** |

Screen recording and share links are not available yet. Current builds upload nothing.

Source code is private. Report problems through the website.
